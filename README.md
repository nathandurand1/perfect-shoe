# The Perfect Shoe

An interactive 3D basketball shoe concept by Nathan Durand (Mechanical Engineering, Iowa State University).

Drag to spin the shoe, use **Explode** to pull the layers apart, and click any part to see why it looks the way it does.

Live site: https://<your-username>.github.io/perfect-shoe/

Built from my Fusion 360 model. The 3D viewer uses three.js.
